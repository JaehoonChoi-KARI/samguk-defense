# 천하통일 디펜스

아이패드용 삼국지 타워 디펜스입니다. 가족이 개인적으로 쓰려고 만들었습니다. 키보드 없이 **터치로만** 합니다.

- 처음 시작할 때 군주(유비, 조조, 손권)와 난이도(쉬움, 보통, 어려움)를 고릅니다. 이 기기에서 엔딩을 한 번 보면 새 게임에서 **지옥** 난이도를 고를 수 있습니다.
- 군주마다 20개 지역짜리 이야기가 있습니다. 황건적의 난부터 삼국지연의 순서로 가고, 마지막은 그 군주가 삼국을 통일하는 가상 이야기입니다(`js/stories.js`).
- 이야기책: 본영의 "이야기"에서 프롤로그와 지금까지 깬 지역의 이야기, 엔딩을 장별로 읽습니다. 지역을 깨면 그 장이 새로 열립니다. 게임 화면의 짧은 글과 달리 삼국지연의 내용을 따라 자세히 쓴 줄글입니다(`js/lore/`). 본영 카드와 천하 지도에는 지난 이야기와 이번 이야기가 짧게 나옵니다.
- 중국 지도에서 지역을 고르고, **정비**(병력 편성, 아이템 챙기기·사기, 장비 확인)를 한 뒤 출진합니다.
- 전투: 길가의 깃발 자리를 눌러 부대를 배치합니다(군량 사용). 배치한 부대를 누르면 승급하거나 철수합니다. 군주는 손가락으로 끌어서 옮기고, 오른쪽 아래 스킬과 왼쪽 아래 아이템(회복 약초, 벽력탄, 목책)을 씁니다.
- PC에서는 마우스로도 합니다. 클릭이 터치와 같고, 군주는 마우스로 끌어서 옮깁니다. 스킬·아이템 조준 중에는 원이 마우스를 따라오고, 오른쪽 클릭이나 Esc로 취소합니다. 메뉴가 없을 때 Esc를 누르면 일시정지합니다.
- 병종 6개(보병, 창병, 기마병, 궁수, 책사, 투석기)는 적도 똑같이 씁니다. 상성은 2단계입니다. 아주 강함 ▲▲ 2배, 강함 ▲ 1.4배, 약함 ▼ 0.7배, 아주 약함 ▼▼ 0.5배. 아주 강함은 한 바퀴 고리입니다: 창병 ⇒ 기마병 ⇒ 궁수 ⇒ 책사 ⇒ 투석기 ⇒ 보병 ⇒ 창병. 상성표는 본영과 일시정지 화면에 있습니다.
- 장수: 진영마다 8~9명이 있고 이야기를 진행하면 합류합니다. 정비에서 2명을 골라 데려가고, 전투에서는 깃발 자리에 무료로 세우는 강한 타워가 됩니다(조종 없음). 장수마다 특수 능력이 하나씩 있고, 힘은 군주 레벨을 따라 오릅니다. 쓰러지면 25초 뒤에 다시 세울 수 있습니다(`data.js`의 `GENERALS`, `GEN_SPECIALS`).
- 성장: 병영(병종 강화, 골드), 군주 레벨(체력·공격·통솔력, 스킬 포인트), 군주 스킬 3개, 장비 3칸(무기·갑옷·보물, 골드로 +10까지 강화).
- 배경음악과 효과음은 브라우저에서 바로 합성합니다. 곡은 모두 이 게임을 위해 새로 쓴 5음계 멜로디라 저작권 문제가 없습니다(`js/music.js`).

**플레이 주소: https://jaehoonchoi-kari.github.io/samguk-defense/**

아이패드 Safari에서 위 주소를 열고 공유 버튼 → "홈 화면에 추가"를 누르면 앱처럼 설치됩니다. 한 번 열고 나면 인터넷이 없어도 실행됩니다.

## 실행

```powershell
pwsh -File serve.ps1          # http://localhost:8000
```

ES module을 쓰기 때문에 `index.html`을 더블클릭해서는 열리지 않습니다. 서버로 열어야 합니다.
같은 Wi-Fi의 아이패드에서는 serve.ps1이 출력하는 주소로 엽니다.

## 자동 테스트와 밸런스 측정

- `http://localhost:8000/?autotest=1`: 데이터 검사, 봇 전투 8판, 터치로 하는 화면 흐름 전체(처음 화면 → 슬롯 → 군주·난이도 → 이야기 → 본영 → 지도 → 정비 → 전투 → 결과 → 나가기), 마우스 조작(가리키기, 조준, 오른쪽 클릭 취소, Esc), 음악 재생. 결과 JSON을 페이지에 출력합니다.
- `http://localhost:8000/?shot=battle&n=9`: 스크린샷용 장면 고정. 이름은 `title`, `slots`, `lord`, `story`, `base`, `map`, `prep`, `picker`, `generals`, `battle`, `boss`, `result`, `barracks`, `lordinfo`, `equip`, `counters`. `lord=caocao`, `n=1..20`, `menu=1`(배치 메뉴), `squad=1`(부대 메뉴)를 붙일 수 있습니다.
- `http://localhost:8000/tools/balance.html?diff=1&runs=2`: 봇이 각 지역을 '그 시점의 평범한 진행 상태'로 플레이하고 승률, 남은 성문, 잃은 부대를 출력합니다. `lords=`, `stages=1-20`, `lvl=`(레벨 추가), `troop=`(병종 레벨 추가), `hp=`·`atk=`(적 배율 시험), `dump=1`.

측정값(봇, 군주 3명 × 20지역 × 3회, 그 지역 권장 레벨의 평범한 진행 상태, 장수 2명):

| 난이도 | 목표 | 승률 | 남은 성문(평균/20) |
|---|---|---|---|
| 쉬움 | 100% | 100% | 19.4 |
| 보통 | 95%, 18 | 99% | 18.2 |
| 어려움 | 90%, 15 | 94% | 15.6 |
| 지옥 | 75%, 10 | 75% | 11.0 |

지옥은 1~5지역은 다 이기고, 16~20지역은 승률 33%라서 레벨을 더 올려야 합니다. 조절 값: `data.js`의 `DIFFS`, `diffScale`, `stageHpMult`, `GENERAL_HP`·`GENERAL_ATK`. 측정 도구의 `gens=0`은 장수 없이 잽니다.

## 파일

| 파일 | 내용 |
|---|---|
| `js/data.js` | 병종·상성·장수·군주·스킬·장비·아이템·난이도 수치와 성장 공식 (밸런스는 여기서) |
| `js/stories.js` | 군주 3명 × 20지역 이야기, 적 구성(mix), 적장, 첫 클리어 보상 |
| `js/lore/*.js` | 이야기책에 실리는 긴 이야기: 군주별 프롤로그, 20장, 엔딩, 장마다 "알고 있나요?" |
| `js/maps.js` | 중국 지도 지명 좌표, 전투 맵의 길 9종과 진지 자동 배치 |
| `js/waves.js` | 적 구성에서 웨이브를 만드는 규칙 (지역마다 늘 같은 웨이브) |
| `js/sim.js` | 전투 규칙 (화면과 분리되어 봇·테스트에서도 그대로 돌아감) |
| `js/render.js`, `js/sprites.js` | 전투 그리기, 병사·군주·성문 그림 |
| `js/battle-ui.js` | 전투 화면 버튼, 배치·승급 메뉴, 터치 입력, 첫 판 안내 |
| `js/screens.js` | 메뉴 화면 전체 |
| `js/chinamap.js` | 천하 지도 그리기 |
| `js/army.js`, `js/progression.js` | 세이브에서 능력치 계산, 전투 보상 |
| `js/bot.js` | 추천 편성, 자동 플레이 봇, 측정용 표준 세이브 |
| `js/music.js`, `js/audio.js` | 배경음악, 효과음 |
| `DESIGN.md` | 기획 메모 |

- 저장: 기기의 localStorage에 세이브 슬롯 3개(`samgukTD.slot.1`~`3`)와 설정(`samgukTD.prefs`).
- 새 버전: `js/data.js`의 `VERSION`과 `sw.js`의 `CACHE`를 같이 올립니다.

## 새 버전 배포

1. `js/data.js`의 `VERSION`과 `sw.js`의 `CACHE`를 같은 새 버전으로 올립니다.
2. 커밋하고 `main`에 push합니다. GitHub Pages가 1~2분 안에 반영합니다.
3. 기기는 인터넷이 연결돼 있으면 게임을 켤 때 최신 버전을 받습니다. 서비스 워커가 네트워크를 먼저 확인하고, 오프라인이거나 4초 넘게 걸리면 캐시를 씁니다. 처음 화면의 버전 버튼을 누르면 바로 업데이트를 확인합니다.
